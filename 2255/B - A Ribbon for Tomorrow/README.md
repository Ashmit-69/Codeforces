Before Chtholly leaves for her next mission, she says nothing and begins preparing a small ribbon for her instead.</p><p>She places $$$n$$$ glass beads in a row on the table before threading them onto the ribbon. Each bead is either white or black. A binary$$$^{\text{∗}}$$$ string $$$s$$$ represents their colors: the character $$$\mathtt{0}$$$ represents a white bead, and the character $$$\mathtt{1}$$$ represents a black bead.</p><p>To make the arrangement less ordinary, Nephren turns it into a small game. She can perform the following operation any number of times (possibly zero):</p><ul> <li> Choose two indices $$$l$$$ and $$$r$$$ ($$$1 \le l \le r \le n$$$) such that $$$s_l=s_r$$$ in the current string, and reverse$$$^{\text{†}}$$$ the substring $$$s_l s_{l+1}\ldots s_r$$$. </li></ul><p>For example, if $$$s=\mathtt{00110}$$$, Nephren may choose $$$l=1$$$ and $$$r=5$$$, since $$$s_1=s_5=\mathtt{0}$$$. Since this number may be large, output it modulo $$$998\,244\,353$$$.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A binary string is a string where each character is either $$$\mathtt 0$$$ or $$$\mathtt 1$$$.</p><p>$$$^{\text{†}}$$$To reverse a substring $$$s_l s_{l+1}\ldots s_r$$$ means to replace it with $$$s_r s_{r-1}\ldots s_l$$$.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
